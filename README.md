# 《信息系统分析与设计》交互式数字教材

> 🌐 **在线阅读（已上线）**：<https://sghpedc5279.github.io/isad-textbook/>

> 苏州大学 社会学院 ·《信息系统分析与设计》（ISAD）课程配套交互式数字教材
> 以「智能体 / 低代码（扣子 Coze）」为主线的重构版，面向信息资源管理专业本科生。

本仓库是课程**数字教材站点**的发布源（与课件 PPT 分离，PPT 不在本仓库）。
教材采用 HTML5 单站结构，可离线打开，也可一键部署到 GitHub Pages。

---

## 一、内容结构

| 文件 | 说明 |
|------|------|
| `index.html` | 门户首页 / 章节导航 |
| `ch01.html` ~ `ch09.html` | 第 1–9 章正文（含导语、学习目标、理论基石、智能体映射、UML、思政、自测、实验、小结） |
| `appendix.html` | 附录（职业与资格导航、前沿文献清单、创新实践汇编等） |
| `style.css` / `app.js` | 站点样式与交互（术语浮窗、自测评分、localStorage 进度、打印导出 PDF） |
| `images/` `media/` | 配图与截图（Coze 实操、微信案例等） |
| `课堂测试*.pptx` | 各章课堂测试 / 雨课堂练习包（站点内提供下载） |
| `教材使用说明.docx` `职业与资格速查表.docx` `前沿文献_候选清单.md` `智能体创新实践汇编_*.{html,md}` | 配套辅助材料 |
| `数字教材_离线版.zip` | 整站离线打包（双击即开，无网络依赖） |

---

## 二、三种使用方式

1. **在线阅读（GitHub Pages）**：浏览器访问 <https://sghpedc5279.github.io/isad-textbook/>（已上线）。
2. **本地直接打开**：下载仓库后双击 `index.html` 即可（相对链接，无需服务器）。
3. **离线包**：下载 `数字教材_离线版.zip` 并解压，双击其中的 `index.html`。

## 五、本地更新流程（供维护者参考）

源稿件在百度同步盘编辑；发布前将改动同步到本仓库目录，再提交推送：

```bash
# 1) 用本机 Python 将 数字教材/ 镜像到本仓库（自动排除备份/临时文件）
python sync_from_baidu.py
# 2) 提交并推送
git add -A
git commit -m "更新：<说明>"
git push -u origin main
```

> 注意：本仓库位于百度同步盘之外，避免云同步干扰 `.git`；请勿把 `.git` 目录放进同步盘。
